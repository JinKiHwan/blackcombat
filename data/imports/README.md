# 블랙컴뱃 선수 명단 수집본

- 출처: https://www.blackcombat-official.com/ranking.php?type=fighter
- 수집일: 2026-10-27 (정확한 UTC 시각은 JSON metadata.collectedAt)
- 범위: 공식 FIGHTER 탭의 9개 부문. 더보기로 숨겨진 행 포함. SEMI-PRO 및 랭킹 미등록 선수는 제외.
- 체급별 등록 174건, 공식 프로필 ID 기준 선수 168명. 여러 체급 등록은 유지하고 선수 엔티티만 ID로 통합.
- CSV: Excel에서 열 수 있는 UTF-8 BOM 형식. 체급별 등록 한 행.
- JSON: metadata(출처/수집 시각), fighters(중복 제거 명단), rankings(체급별 등록).

## 필드와 주의점

fighterId는 공식 사이트 프로필 ID이며 Firebase 문서 ID로 사용할 수 있습니다. ringName은 링네임, name은 공식 페이지의 선수 이름 표기입니다. 영문 이름과 띄어쓰기는 원문을 유지했습니다. countryCode는 원문 국기 코드입니다.

champion은 챔피언 여부이며 챔피언 rank는 null입니다. rankChange는 공식 페이지의 순위 변동 원문입니다. recordRaw는 원문의 세 숫자를 그대로 보존했습니다. 전체 프로 전적인지 단체 내 전적인지와 각 숫자의 의미는 별도 검증 전이므로 자동 계산에 사용하지 않습니다.

챔피언 공석은 선수가 아니므로 제외했습니다. 신장·리치·소속·개별 경기 이력은 이번 랭킹 페이지 수집 범위에 포함되지 않습니다. 공식 프로필 링크를 통해 추가 검증할 수 있습니다.

## 프로필 이미지

각 선수 프로필의 `.fighter_img img`에서 실제 src를 추출해 `public/images/fighters/{fighterId}.{확장자}`로 저장했습니다. 168명 중 161명 다운로드, 7명은 원본이 기본 실루엣(placeholder)이며 수집 실패는 없습니다. 확장자는 응답의 실제 이미지 형식으로 판단합니다.

`blackcombat-fighter-images.json`에 선수별 원본 URL, 로컬 경로, 수집 시각, 상태를 기록했습니다. 선수 JSON의 `profileImage`에도 해당 경로와 상태를 연결했습니다. CSV에는 이미지 필드를 추가하지 않았습니다. 홈페이지에는 아직 연결하지 않았습니다.

재실행: `node scripts/collect-fighter-images.mjs`. 요청은 순차 처리하고 간격을 두며, 기존 정상 이미지 파일은 재다운로드하지 않습니다. 실패 시 다음 선수로 진행하고 manifest에 오류를 남깁니다. 이미지 URL은 재배포 허가를 뜻하지 않으므로 공개 사용 전 원본 이미지의 이용 권한을 확인해야 합니다.

## 검증

174개 등록 행의 프로필 ID, 이름/링네임, 체급, 전적 형식, 순위 정수 여부를 검사했습니다. 같은 체급/프로필 ID 중복은 없으며, 복수 체급 선수의 전적 표기 충돌도 없습니다. 초기 표시 상위 10명 외의 숨김 행도 포함합니다.

이 파일은 일회 수집 스냅샷이며 홈페이지나 Firebase에는 아직 연결하지 않았습니다. 최신 순위 자동 갱신 기능은 포함하지 않습니다.

## HEIGHT / TEAM 추가 수집 (2026-10-27)

전체 168명 공식 프로필의 `.data_bio_height`와 `.data_team`을 수집했습니다. 위의 최초 랭킹 수집 범위와 별개로 신장과 소속이 추가되었습니다. JSON fighters의 height/team과 CSV의 height/team 열에서 확인할 수 있습니다. 신장은 168명 모두 확인했으며, TEAM은 34명이 원문 N/A, 2명(무사·파라오)은 빈 값으로 null을 저장했습니다. 나머지 132명은 원문 소속을 보존했습니다. profileDetails에 개별 출처·수집 시각·상태를 기록했습니다. REACH는 이번 수집에 포함하지 않았습니다.

재실행: `node scripts/collect-fighter-details.mjs`. 이미 수집 성공한 선수는 건너뛰고 실패 항목만 재시도합니다. 넘버링 17의 5개 대진은 선수 JSON의 height/team을 읽습니다.

## 이벤트 목록·상세 수집 (2026-10-27)

`blackcombat-events.json`은 공식 `event.php?eventCategory=...` 5개 카테고리의 65개 이벤트와 454개 대진을 저장한 스냅샷입니다. NUMBERING 17건, BLACK CUP 6건, RISE 9건, CHAMPIONS LEAGUES 30건, ETC 3건입니다. 초기 목록에서 페이지네이션 링크는 없었으며 각 카테고리 응답의 전체 목록을 수집했습니다.

목록은 `/events`, 상세는 `/events/{공식 이벤트 ID}`입니다. 넘버링17은 사용자가 지정한 5개 대진을 유지하기 위해 `/numbering/17`로 연결합니다. 그 외 상세는 공식 이벤트의 링네임·본명·당시 전적 표기·체급별 순위 표기·Win 표시를 사용합니다. 당시 신장·리치·팀 정보는 수집하지 않았으며 현재 팀을 역사 데이터로 대체하지 않습니다. 선수 이미지는 로컬 보유 이미지 우선, 없는 선수만 공식 상세의 이미지 URL을 사용합니다.

포스터는 `public/images/events`에 저장했습니다. 과거 경기에는 예측 투표·응원 입력을 표시하지 않습니다. 향후 상세 수집 실패나 빈 대진 항목은 목록 클릭 시 '데이터가 없습니다.' 레이어가 뜹니다. 공식 승리 표시가 없으면 '결과 정보 미등록'으로 표기하며 무승부·무효 여부를 추정하지 않습니다. 자동 갱신 기능은 포함하지 않습니다.
